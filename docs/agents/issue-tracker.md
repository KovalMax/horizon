# Issue tracker: Local Markdown

Specs and issues for this project live as Markdown files in `.scratch/`.

## Conventions

- One feature per directory: `.scratch/<feature-slug>/`
- The feature spec is `.scratch/<feature-slug>/spec.md`
- Implementation issues are separate files under `.scratch/<feature-slug>/issues/`, numbered from `01` (for example, `01-<slug>.md`)
- Add follow-up decisions or discussion to the relevant document under a `## Comments` heading.

When a skill says to publish a spec or issue, create the corresponding file under `.scratch/<feature-slug>/`.
